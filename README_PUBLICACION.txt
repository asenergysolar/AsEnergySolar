A.S ENERGY — SITIO WEB AUTÓNOMO

Esta versión integra las imágenes directamente dentro de index.html (base64).
No depende de rutas de imágenes, CDNs ni de una carpeta assets para mostrar las imágenes.

PUBLICACIÓN EN GITHUB PAGES
1. Descomprime este ZIP en tu computador o teléfono.
2. En el repositorio de GitHub, entra a la raíz (Code).
3. Sube/reemplaza index.html, styles.css y script.js en la raíz del repositorio.
4. Guarda los cambios (Commit changes) y espera a que GitHub Pages termine el despliegue.
5. Abre la página y actualízala sin caché.

IMPORTANTE: index.html contiene todas las imágenes incrustadas; aun así, conserva styles.css y script.js para que el diseño y las funciones trabajen correctamente.
El logo, el contacto y los textos del sitio se mantienen.
