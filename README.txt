PUBLICAR EN GITHUB PAGES
1. Descarga y descomprime este ZIP en tu computador o celular.
2. Entra a https://github.com y crea un repositorio público, por ejemplo: as-energy-web.
3. En el repositorio, pulsa Add file > Upload files.
4. Sube TODO el contenido de esta carpeta (index.html, styles.css, script.js, robots.txt y la carpeta assets). Los archivos deben quedar en la raíz del repositorio, no dentro de otra subcarpeta.
5. Pulsa Commit changes.
6. Abre Settings > Pages.
7. En Build and deployment selecciona Deploy from a branch.
8. Selecciona Branch: main y Folder: /(root). Pulsa Save.
9. Espera a que GitHub termine la publicación. La dirección aparecerá en Settings > Pages y tendrá una forma parecida a https://TU-USUARIO.github.io/as-energy-web/.

IMPORTANTE PARA SEO
- Después de publicar, abre sitemap-template.xml, cambia la URL de ejemplo por la URL real y guárdalo como sitemap.xml. Súbelo a la raíz del repositorio.
- En el bloque JSON-LD de index.html, completa el campo "url" con la URL real del sitio (entre comillas).
- Para conectar un dominio propio, primero configura el dominio en Settings > Pages y luego los registros DNS donde compraste el dominio. No inventes ni copies registros DNS de otro proveedor.
