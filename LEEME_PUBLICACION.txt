A.S ENERGY — PAQUETE LISTO PARA PUBLICAR EN GITHUB PAGES

CONTENIDO
- index.html: página principal completa.
- styles.css: estilos adaptables a celular y computador.
- script.js: menú, formulario de WhatsApp y carrusel.
- assets/: las 37 fotografías locales en formato JPEG.
- .nojekyll: evita que GitHub Pages omita archivos por reglas de Jekyll.

PUBLICACIÓN (IMPORTANTE)
1. Abre https://github.com/asenergysolar/AsEnergySolar
2. Entra a la pestaña Code.
3. Elimina o reemplaza los archivos antiguos del sitio para evitar mezclar versiones.
4. Sube TODO el contenido de este ZIP a la raíz del repositorio. Debes ver index.html, styles.css, script.js y la carpeta assets al mismo nivel.
5. Entra en Settings > Pages y verifica que la fuente sea Deploy from a branch, rama main y carpeta /(root), si esa es la configuración que usa el repositorio.
6. Espera a que termine el despliegue y abre https://asenergysolar.github.io/AsEnergySolar/

NO subas solamente index.html. La carpeta assets completa es indispensable para que aparezcan las fotografías. No pongas los archivos dentro de otra carpeta adicional.

COMPROBACIONES LOCALES
